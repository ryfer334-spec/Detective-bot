# ДЕТЕКТИВ — облачный Telegram-бот для двух друзей

## Что уже реализовано
- комнаты на двоих, приглашение по коду;
- переписка с напарником через `/say`;
- сюжетные расследования, улики и обвинение;
- загадки, тайные задания;
- профиль, XP и уровни;
- SQLite для хранения профилей и комнат.

## 1. Получить токен
В Telegram откройте `@BotFather`, отправьте `/newbot`, задайте имя и username. Скопируйте токен. Не публикуйте его и не отправляйте никому.

## 2. Облачный запуск через Docker
На VPS или облаке с постоянно работающим Docker worker:
```bash
docker build -t detective-bot .
docker run -d --name detective-bot --restart unless-stopped \
  -e BOT_TOKEN='ВАШ_ТОКЕН' \
  -v detective-data:/app \
  detective-bot
```
Для облачной платформы задайте переменную окружения `BOT_TOKEN`, используйте Dockerfile и подключите постоянный диск к `/app`. Бот работает через long polling — публичный URL и webhook не требуются. Выбирайте тариф, который не останавливает фоновые процессы; бесплатные тарифы могут «усыплять» бота.

## 3. Локальный запуск для проверки
Python 3.12+:
```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
export BOT_TOKEN='ВАШ_ТОКЕН'
python bot.py
```
В Windows PowerShell: `$env:BOT_TOKEN='ВАШ_ТОКЕН'`.

## 4. Как начать игру
1. Ты и друг открываете бота и нажимаете `/start`.
2. Ты нажимаешь «Создать комнату» и отправляешь другу код.
3. Друг нажимает «Ввести код» и пишет `/join КОД`.
4. Запускайте `/case`, открывайте `/clue`, обсуждайте версии через `/say текст`.
5. Обвинение: `/accuse 1`, `/accuse 2` или `/accuse 3`.
6. Дополнительно: `/puzzle`, `/answer ответ`, кнопки «Тайное задание» и «Мой профиль».

## Важно
Это рабочая стартовая версия (MVP), рассчитанная на тестирование между двумя друзьями. Перед публичным запуском стоит добавить админ-команды, защиту от спама, резервные копии, тесты, более длинную библиотеку дел и улучшенную обработку игровых сессий. Не передавайте через бота пароли, платёжные данные и другую чувствительную информацию.
